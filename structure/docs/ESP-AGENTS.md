# Mis Webs

Aplicación web personal para almacenar y consultar información desde cualquier dispositivo (páginas web, software, comandos, etc.).

## Stack
- HTML, CSS y JavaScript.
- Bootstrap 5.3.3.
- Sin base de datos ni dependencias externas.

## Estructura
- `index.html`: punto de entrada y navegación.
- `js/`: módulos (`fileFunctions.js`, `modalFunctions.js`, `templatesFunctions.js`, `structureFunctions.js`).
- `css/`: estilos (`custom.css`, `structure.css`).
- `templates/`: plantillas HTML por sección (IA, Developer, PC, Games, etc.).
- `structure/`: componentes compartidos (`modals.html`).
- `bootstrap-5.3.3-dist/`: Bootstrap.
- `docker-compose.yml`: despliegue.

## Convenciones
- Mantén una estructura organizada.
- Cada funcionalidad debe estar en su archivo y carpeta correspondiente.
- Reutiliza código existente; evita duplicar lógica.
- Mantén el estilo del proyecto y modifica solo lo necesario.
- Comenta funciones o lógica no evidente.

## Restricciones
- No instales dependencias ni cambies el stack sin consultarme.

## Flujo de trabajo
1. Analiza el proyecto antes de realizar cambios.
2. Para tareas no triviales, propón un plan y espera mi aprobación.
3. Realiza una tarea cada vez.
4. Al finalizar, resume los cambios realizados.
5. Si tienes menos del 80% de certeza, pregunta en lugar de asumir.
